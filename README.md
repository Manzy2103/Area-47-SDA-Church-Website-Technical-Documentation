# Area-47-SDA-Church-Website-Technical-Documentation
A technical case study documenting the development, deployment and infrastructure management of the Area 47 Seventh-day Adventist Church website.

## Overview
The Area 47 SDA website is a django-based web platform developed to support the church's online presence and digital operations.

This repository documents the technical work behind the platform, with a focus on backend development, database management, Linux server administration, deployment workflows and infrastructure.

The purpose of this documentation is to explain how the system is structured, how its components work together, the technical decisions made during development, and the challenges encountered along the way.

## Technology Stack

The project uses a combination of technologies across backend development, frontend tooling, infrastructure and deployment

| Area | Technologies |
|---|---|
| Backend | Python, Django |
| Database | PostgreSQL |
| Frontend tooling | Vite, Tailwind CSS, Alpine.js |
| Background processing | Celery, Redis |
| Web server | Nginx |
| Application server | Gunicorn |
| Operating system | Ubuntu Linux |
| Deployment | Git, Docker |
| Email infrastructure | Postfix, Dovecot, OpenDKIM |
| Other | Service Workers, Web Push Notifications |

*Technologies are listed to describe the project; individual implementation details and completion status will be documented in the relevant sections*
